# 규로마 상세 가이드

규로마(GYUROMA)는 색칠된 3D 모델의 어지러운 색을 **몇 가지 깔끔한 색**으로 정리해서, 멀티컬러 프린터가 그대로 뽑을 수 있는 파일로 만들어 주는 앱입니다. 작업은 네 단계로 갑니다.

**01 불러오기 → 02 색 정리 → 03 필라멘트·혼합 → 04 내보내기**

모든 계산은 이 브라우저 안에서 끝납니다. 넣은 파일은 내 컴퓨터에만 있습니다.

![규로마 전체 화면](overview)

## 화면 한눈에

- **위 막대** — 왼쪽부터 파일 칩(파일 이름 · 면 수 · 저장 점 · 파일로 저장), 단계 01~04(끝낸 단계엔 체크), ↶ ↷ 되돌리기·다시 하기(옆 숫자 = 남은 칸), 앱 가이드, ? 도움말(용어집 · 이 가이드), ⚙ 설정, 3MF 내보내기.
- **왼쪽 패널** — 그 단계에서 할 일. 맨 아래 굵은 버튼(02 **정리 실행**, 04 **3MF 내보내기**)은 내용을 내려도 늘 그 자리에 있습니다.
- **가운데 3D 화면** — 원본 · 비교 · 결과를 나란히 보고, 결과는 **팔레트**(정리한 색)나 **출력 시뮬레이션**(실제로 찍힐 색)으로 봅니다. 오른쪽 위 보기 도구로 방향 · 평면색 · 형태 선 · 부드러운 경계 · 선 따라 자르기를 켜고 끕니다.
- **아래 도구 독** — 손으로 고치는 도구들(아래 '손으로 고치는 도구').
- **오른쪽 패널** — 02 색 스펙트럼, 03 레시피, 04 줄무늬 점검.

3D 화면 조작: **드래그** 회전 · **휠** 확대 · **스페이스를 누른 채 드래그**(또는 오른쪽 드래그) 이동.

## 01 불러오기

이런 파일을 넣을 수 있습니다.

- **정점색 OBJ** — 노마드 스컬프 · 블렌더에서 정점색으로 내보낸 것
- **면 색 3MF** — 면 색(Face Color)으로 내보낸 3MF
- **.gyuroma 작업 파일** — 규로마에서 저장한 작업(모델 · 색 · 자르기 · 설정이 한 파일에)

**템플릿 3MF**는 선택입니다. 프루사슬라이서에서 프린터 프로필과 필라멘트를 지정해 저장한 빈 프로젝트를 넣으면, 베드 크기와 꽂힌 필라멘트 색을 가져와 03 슬롯을 채워 줍니다.

모델을 열면 **작업 상태**에서 자동 저장을 켜고 끄고, **원본 색으로** 되돌리거나, **작업 파일로 저장**하거나, **새로 시작**할 수 있습니다.

## 02 색 정리

### 목표 색 수

왼쪽 맨 위 숫자가 최종 색 개수입니다(8 · 12 · 16 · 24 바로 고르기). 바꾸면 색 띠의 경계를 다시 깝니다.

### 색 스펙트럼 (오른쪽 색 띠)

색 띠 하나가 최종 색 하나입니다. 띠 높이는 그 색이 차지하는 면적이고, 오른쪽 칩(E1 · VE7 …)은 그 색이 출력될 필라멘트입니다.

- **경계를 끌기** — 색이 옆 띠로 옮겨 갑니다. 상대 띠의 절반을 넘기면 통째로 합쳐집니다.
- **⇧ 누른 채 끌기** — 조금씩 옮겨 밝은 쪽 · 어두운 쪽 경계를 맞춥니다.
- **띠를 두 번 누르기** — 띠를 둘로 나눕니다.
- **면적 비례 / 균등** — 작은 색이 많으면 '균등'으로 보면 다루기 쉽습니다.

![02 색 정리](tidy)

### 자동 정돈 프리셋

버튼에 마우스를 올리면 무엇이 얼마나 바뀌는지 먼저 보여 줍니다. **적용할 곳**(모델 전체 · 고른 조각만)과 **바꿀 설정**(색정리 · 혼합 · 둘 다)을 고를 수 있습니다.

| 프리셋 | 하는 일 |
|---|---|
| 경계 또렷하게 | 색과 색 사이 경계를 반듯하게, 작은 얼룩은 둘레 색으로 |
| 그라데이션 살리기 | 밝은 곳에서 어두운 곳으로 가는 음영을 여러 계단으로 남김 |
| 단색으로 깔끔하게 | 부위마다 한 색으로 평평하게 |
| 작은 디테일 지키기 | 눈동자 · 볼 · 리본 같은 작은 색을 최대한 살림 |
| 톱니 깎기 | 경계에서 가늘게 삐죽 나온 삼각형(가시)을 깎음 |
| 경계 매끈하게 | 계단 · 지그재그 경계를 완만한 선으로 다시 그음 |

### 정리 실행

마음에 들면 왼쪽 아래 **정리 실행**을 누릅니다. 지금 띠대로 면 색을 확정하고, 경계 톱니와 작은 조각도 같이 정리합니다. ⌘Z로 되돌릴 수 있습니다.

## 손으로 고치는 도구

화면 아래 도구 독입니다. 버튼 아래 글자가 단축키입니다.

| 도구 | 키 | 하는 일 |
|---|---|---|
| 선택 | V | 조각을 눌러 고르기 · ⇧로 더하기 |
| 브러시 | B | 왼쪽 드래그로 칠하기 · `[` `]` 크기 · `S` 고른 조각 안에서만 |
| 힐링 | H | 문지르면 점 · 얼룩이 둘러싼 색으로 지워짐(색 안 골라도 됨) |
| 채우기 | G | 누른 조각 전체를 이 색으로 · 마우스를 올리면 채울 곳이 미리 보임 |
| 스포이드 | I | 모델에서 색 집기 |
| 틈새 정리 | C | 두 색 사이에 낀 다른 색 조각을 지움 |
| 가상선 | L | 표면을 따라 안내선을 그음(칠하지 않음 · 모델별로 저장) |
| 색지도 | M | 모델 표면을 평면 지도로 펼쳐 봄 |
| 맞춤 | F | 모델을 화면에 맞춤 |

브러시를 쓰는 동안: 왼쪽 드래그 칠하기 · 오른쪽 드래그 회전 · 스페이스+드래그 이동 · 휠 확대.

## 색지도와 펼치기

**색지도(M)**는 모델 표면을 평면에 펼친 지도입니다. 3D에서 손이 닿기 어려운 안쪽 · 뒷면도 지도에서 바로 칠할 수 있고, 3D와 지도는 서로 같은 자리를 가리켜 줍니다.

- **고른 조각 펼치기** — 조각을 누르면 그 조각만 한 장으로 펼칩니다(블렌더 언랩처럼 각도를 지키며). 큰 조각은 그래픽 카드로 계산해서 빠릅니다.
- **붙은 면도 같이** — 고른 조각 둘레의 다른 색 면까지 띠처럼 같이 펼칩니다. 지도에서 경계를 넓히거나 고칠 때 씁니다. 옆 **넓이**로 띠를 ×8까지 넓힙니다.
- **↩ 고른 조각 접기** — 전체 지도로 돌아갑니다. 빈 곳을 누르거나 Esc도 같습니다.

## 03 필라멘트·혼합

- **프린터 슬롯** — 프린터에 꽂은 필라멘트(E1~). 색 칸을 눌러 바꾸거나 #RRGGBB를 직접 적습니다.
- **보관함** — 집에 있는 필라멘트를 넣어 두면 이 모델에 가장 잘 맞는 조합을 골라 줍니다.
- **혼합 설정** — 꽂지 않은 색은 필라멘트를 **층마다 번갈아 쌓아서** 만듭니다. 섞는 색 수(단색만 · 2색까지 · 3색까지)와 층 비율 간격을 정합니다.

### 매핑 표 읽는 법

| 칸 | 뜻 |
|---|---|
| E1~E5 | 한 주기에 그 필라멘트를 몇 층 쌓는지(밑의 막대 = 비율) |
| 예측 | 왼쪽 = 원하는 색, 오른쪽 = 찍힐 색 |
| ΔE | 두 색의 차이 — 5 넘으면 노랑, 10 넘으면 빨강 |
| 원본 색 | 원하는 색에 얼마나 가까운지(%) |
| 주기 · 층 순서 | 한 번 반복되는 층 수와 실제로 쌓는 순서 |
| 출력 | 슬라이서에서 보일 익스트루더(E = 단색, VE = 섞은 색) |

표에서 줄을 누르면 오른쪽 **레시피**에서 그 색의 층 수를 바꾸거나 **다른 조합**을 고를 수 있습니다.

![03 필라멘트·혼합](mix)

## 04 내보내기

1. **프린터**를 고릅니다. 프린터마다 여는 프로그램 · 필라멘트 수 · 베드 · 층 섞기가 달라서, 고르면 파일 형식과 검사 기준이 맞춰집니다.
   - **프루사 XL · MMU3 · INDX** — 프루사슬라이서 2.9.6 이상에서 층을 섞은 색까지 그대로 뽑습니다.
   - **밤부랩**(AMS · H2D · H2C 등) — 밤부 스튜디오 2.8 이상에서 프로젝트로 열립니다. 섞는 색은 혼합 필라멘트로 들어갑니다.
   - **크리얼리티 · 엘레구 · 애니큐빅 · QIDI · 스냅메이커 · 플래시포지** — 꽂은 색 그대로(실물 색만) 뽑도록 맞춰 줍니다.
   - **풀컬러 프린터**(잉크젯 · UV · 분말) — 02에서 정리한 색을 그대로 담은 색 파일로 내보냅니다.
2. **프린터 툴 순서 확인** — 앱의 E1~E5 순서가 프린터에 꽂은 툴 순서와 같아야 색이 맞습니다.
3. **출력 품질** — 템플릿 그대로 · 최상 0.10 · **높음 · 겉면 천천히** 0.15 · **보통 · 빠르게** 0.15 · 빠름 0.20 · 초고속 0.25. 두 0.15는 층 높이가 같고 겉면 속도가 다릅니다(피규어처럼 겉이 보이는 출력은 '겉면 천천히').
4. 크기 · 바닥 면 · 최종 점검을 보고, 오른쪽 **줄무늬 점검**에서 섞은 색이 줄로 보일지 확인합니다.
5. 왼쪽 아래 **3MF 내보내기** — **이 프린터로 내보낼까요?** 창에 프린터 이름 · 여는 프로그램 · 필라멘트 칸이 크게 뜹니다. 맞으면 **이 프린터로 내보내기**, 아니면 그 창의 **다른 프린터**에서 바로 바꿉니다. 파일은 브라우저 다운로드 폴더에 저장됩니다. 프루사슬라이서에서는 **⌘O(프로젝트 열기)**로, 밤부 스튜디오에서는 **프로젝트 열기**로 엽니다.

완성한 3MF 여러 개를 한 판에 뽑을 때는 **모아 뽑기**를 엽니다. 프루사슬라이서 · 밤부 스튜디오 파일을 하나로 합쳐 판 위에 겹치지 않게 놓아 줍니다.

## ⚙ 성능 · 메모리

⚙ 설정 → **성능 · 메모리…**에서 바꿉니다. 바꾸면 바로 적용되고, 창 위에 이 컴퓨터가 할 수 있는 것(그래픽 카드 계산 · CPU 코어 수 · 메모리 한도)이 나옵니다.

| 설정 | 하는 일 |
|---|---|
| 그래픽 카드로 펼치기 | 색지도의 조각 펼치기를 그래픽 카드(WebGPU)로 계산 — 큰 조각이 몇 배 빠름. 끄면 CPU가 같은 계산 |
| 3D 화면 선명도 | 자동 · 1× · 1.5× · 2× — 낮추면 그리는 점이 줄어 돌리기 · 붓질이 가벼움 |
| 강조 깜빡임 | 새로 고른 곳 · 바뀐 곳이 두 번 깜빡임. 끄면 바로 보이고 더 가벼움 |
| 메모리 아끼기 | 자동 · 켬 · 끔 — 켜면 되돌리기 8칸 · 자르기 되돌리기 2칸 · 캐시를 줄이고, 숨은 3D 화면은 그래픽 카드 메모리를 놓음. 자동 = 200만 면 넘는 모델 |
| 내보내기를 따로 하는 코어에서 | 3MF를 화면과 다른 CPU 코어에서 씀 — 큰 모델을 내보내는 동안에도 화면이 멈추지 않음(전체 시간은 조금 늘어남) |
| 3MF 내보내기 압축 | 작게 · 빠르게 — 빠르게는 내보내기가 조금 빨라지고 파일이 8%쯤 커짐 |

## 저장

- **자동 저장** — 공개 사이트에서는 이 브라우저 안에, 내 컴퓨터에서 '규로마 실행'으로 켜면 규로마 폴더의 user-data에 저장됩니다. 저장 상태는 위 막대 파일 칩의 점으로 보입니다(마우스를 올리면 글로).
- **저장이 잠깐 안 되면** — 파일 칩의 **저장 실패**를 누르면 바로 다시 저장합니다(그대로 두어도 잠시 뒤 저절로). 이 맥의 규로마는 저장할 때마다 바로 전 사본을 하나 남겨, 기록이 깨져도 그 사본으로 되살립니다.
- **파일로 저장** — 소중한 작업은 .gyuroma 작업 파일로 남겨 두세요. 01 불러오기 칸에 넣으면 어느 컴퓨터 · 브라우저에서든 그대로 열립니다.
- **설정 저장** — 필라멘트 목록 · 혼합 같은 설정은 ⚙ 설정 → 설정 저장으로 JSON 파일로 받아 둡니다.
- **다시 받기** — 내보낸 파일이 다운로드 폴더에 안 보이면 04 왼쪽 아래 '다시 받기'를 누릅니다.

## 이럴 땐

- **화면이 버벅여요** — ⚙ 성능 · 메모리에서 3D 화면 선명도를 1×로, 강조 깜빡임을 끔으로. 큰 모델이면 메모리 아끼기를 켭니다.
- **아래 상태 줄이 '저장: 브라우저만 ⚠'이에요** — 규로마 실행으로 다시 켠 뒤 새로고침하면 다시 폴더에 저장됩니다.
- **다른 컴퓨터에서 이어 하고 싶어요** — 01의 **작업 파일로 저장**으로 .gyuroma를 받아 두고, 그 컴퓨터의 01 불러오기 칸에 넣으면 됩니다. 아주 큰 3MF(수백만 면)도 그대로 열립니다.
- **내보내기를 더 빨리** — 3MF 내보내기 압축을 '빠르게'로.
